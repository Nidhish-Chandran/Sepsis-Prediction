About SepsisLens

Project background, machine learning methodology, and evaluation benchmarks.

Project Overview

Sepsis is a life-threatening medical emergency caused by the body's dysregulated response to an infection. In intensive care units (ICUs), early detection is critical because each hour of delay in antibiotic intervention significantly increases patient mortality risk.

SepsisLens is an academic MCA machine-learning project developed to demonstrate early sepsis prediction using supervised classification models trained on multivariate ICU physiological time-series data.

Dataset and Model
Dataset Source

PhysioNet / Computing in Cardiology Challenge 2019 ICU cohort, comprising de-identified patient time-series records from two hospital systems.

Selected Model Architecture

Random Forest ensemble (300 decision trees) trained across 164 temporal engineered features (vital signs, rolling averages, rate-of-change, and missingness indicators).

Data Leakage Prevention

Strict patient-level stratified splitting (70% train / 15% validation / 15% test) ensuring no patient records appear across multiple partitions.

Technology Stack

Python 3.11, Django 5.2, Scikit-Learn 1.5, Pandas, SHAP, and Bootstrap 5.

Model Selection Rationale: Model superiority depends on the clinical objective. While Random Forest produced the best overall discrimination across decision thresholds (ROC-AUC 0.7834), Logistic Regression produced higher F1 (0.1503) and precision (0.1221), and Decision Tree had higher recall (0.3822). Random Forest was selected for robust overall discrimination on patient-level splits.
Project Limitations
  • Measurement Sparsity: Real-world ICU lab tests are sampled irregularly, requiring median imputation and forward-filling.
  • Uncalibrated Ensemble Scores: Random Forest outputs represent decision-tree vote fractions rather than calibrated probabilities.
  • Retrospective Cohort: Evaluated on retrospective PhysioNet 2019 ICU data; clinical deployment requires prospective streaming validation across distinct healthcare systems.
