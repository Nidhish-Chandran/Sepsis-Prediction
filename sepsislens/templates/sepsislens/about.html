About SepsisLens

Project background, machine learning methodology, and evaluation benchmarks.

Project Overview

Sepsis is a life-threatening medical emergency caused by the body's overwhelming response to an infection. In intensive care units (ICUs), early detection is vital because each hour of delay in antibiotic intervention significantly increases mortality risk.

SepsisLens is an academic MCA project designed to demonstrate early sepsis prediction using machine learning. It monitors multi-parameter ICU vital signs and laboratory measurements to detect early indicators up to 6 hours before clinical diagnosis criteria are met.

Dataset & Model Details
Dataset Source

PhysioNet / Computing in Cardiology Challenge 2019 ICU cohort, comprising de-identified patient time-series records from two hospital systems.

Trained Model

Random Forest ensemble (300 decision trees) trained across 164 engineered features (vital signs, rolling averages, rate-of-change, and missingness indicators).

Data Leakage Prevention

Strict patient-level stratified splitting (70% train / 15% validation / 15% test) ensuring no patient records appear across multiple partitions.

Technology Stack

Python 3.11, Django 5.2, Scikit-Learn 1.5, Pandas, SHAP, and Bootstrap 5.

Project Limitations
  • Measurement Sparsity: Real-world ICU lab tests are sampled irregularly, requiring median imputation and forward-filling.
  • Uncalibrated Ensemble Scores: Random Forest outputs represent decision-tree vote fractions rather than calibrated probabilities.
  • Retrospective Cohort: Evaluated on retrospective PhysioNet 2019 ICU data; clinical deployment requires prospective validation across distinct healthcare systems.
